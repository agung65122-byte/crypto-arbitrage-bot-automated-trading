## 📈 Understanding Arbitrage
Arbitrage means buying an asset on one exchange at a lower price and selling it on another exchange at a higher price. This bot monitors these price gaps. When a gap appears, the bot executes trades to capture the difference. The system works as an agent to handle execution timing. This removes the need for manual monitoring.
